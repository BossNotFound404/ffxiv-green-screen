# Green Screen / 绿幕 v0.9.0-preview.1 使用说明

本版适配 Windows x64 与卫月 API 15。纯色棚用 Penumbra 1.7.2.1、Hyperborea 1.0.1.2 和本机生成的布景。Stable Stage v0.18 提供六种底色；原有 v0.16 提供五种。想在普通场地录制蓝扇序列，可以直接配置蓝扇采集扩展。[录蓝扇 AE 序列](#录蓝扇-ae-序列)

## 前置插件从哪里安装

以下是摄影棚各项功能使用的卫月插件。对于自定义仓库，在游戏中输入 `/xlsettings`，在「实验性」的「自定义插件仓库」里粘贴表中链接的地址，点加号并保存。输入 `/xlplugins`，搜索插件名并安装、启用。「开发插件位置」用于加载解压到本机的绿幕 DLL。[卫月安装说明](https://dalamud.dev/faq/getting-started/)

| 插件 | 适用场景 | 安装来源 |
|---|---|---|
| Penumbra 1.7.2.1 | 必需。首次使用时完成模组目录设置，开启模组并保留可用的默认集合。 | [Penumbra 插件仓库](https://raw.githubusercontent.com/xivdev/Penumbra/master/repo.json) · [对应发布页](https://github.com/xivdev/Penumbra/releases/tag/1.7.2.1) |
| Hyperborea 1.0.1.2 | 一键进退棚必需。安装正式版并让卫月加载它，面板里的 Enable 由绿幕按需打开。 | [Hyperborea 插件仓库](https://puni.sh/api/repository/kawaii) · [作者的安装步骤](https://github.com/kawaii/Hyperborea#download--install) |

## 升级一次

1. 若当前还在旧版棚内，先用「退棚」返回旅馆。使用较早版本时，可在 Hyperborea 点 **Revert**。回到旅馆后停用旧开发插件。
2. 将预览版程序包完整解压到新文件夹。初次进六色棚时，从自己的客户端生成 **RoundTable_StableStage_v0.18.pmp**，放在 DLL 旁。试用天幕修正时再加入 **RoundTable_CaptureStage_v0.19.pmp**。已有 v0.16 或 v0.17 的用户可以继续用对应的五色布景。[棚包构建说明](build.md)
3. 在卫月开发插件设置中选择新目录下的 **RoundTableStudio.dll** 并启用。插件显示为 **Green Screen / 绿幕**，原有设置和 **/rtstudio** 命令继续可用。

## 平时怎么拍

在旅馆输入 **/rtstudio**，点 **进入摄影棚**。也可直接输入 **/rtstudio 进棚**。插件首次使用时自动导入棚包，以后会复用已有的棚包。

如果卫月已经加载适配版 Hyperborea，而它面板中的 **Enable Hyperborea** 尚未勾选，录制棚会调用原面板的开启动作，确认开启后继续进棚。若这个开关是录制棚打开的，回到原旅馆后会调用原面板的关闭动作。进棚前已勾选的开关会保留。

使用 v0.18 或 v0.19 进棚后，面板上有 **黑、白、中灰、红、绿、蓝** 六个选色按钮，实心圆表示当前选择。第一次使用从黑棚开始，以后沿用上次选的棚色。也可输入 **/rtstudio 白** 等命令换色，用 VFXEditor 播放要录的特效。

| 操作 | 面板用法 |
|---|---|
| 拍角色施放的技能 | 摆好机位，点 **拍角色技能**，等到面板提示可以施放时按一次技能快捷键。拍完点「打开结果文件夹」，可取黑棚原帧 **black.png** 和用于「添加」混合的 **glow-add.png**。 |
| 拍 VFXEditor 地面预览 | 用 VFXEditor 1.9.4.6 的 **Spawn → On Ground** 放一个地面预览，加载 Brio 0.8.0.12，等到想要的瞬间点 **拍地面预览**。通过对照的输出叫 **effect.png**。出现误差时保留实拍、候选图和报告。[拍摄与对照说明](alpha-export.md) |
| 把当前目标换成怪物或 Boss | 在游戏里选中要替换的角色（可以选本人），展开「拍摄设置 → 替换目标模型」。下拉框可选伊弗利特、迦楼罗、泰坦、利维亚桑、俾斯麦、萨菲洛特、索菲娅、祖尔宛。也可填入其他怪物的 **ModelChara 行号**。点「替换当前目标」，等模型重新显示。换选目标后，「还原目标模型」仍作用于刚才替换的那个角色。退棚也会请求还原。 |
| 拍全贴地扇形 | 进棚时沿用当前视距。普通第三人称镜头自动放宽俯仰范围，可以接近垂直俯拍。需要更远的机位时，在「拍摄设置」点「扩展至 100」并滚轮拉远，或输入数值并点「应用距离」。 |
| 用自由镜头取景 | 点「开启 Freecam」，按 Cammy 的操作方式移动，再点「关闭 Freecam」结束。进棚前已经开启的自由镜头会保留。录制棚开启的镜头可随退棚收回。 |
| 隐藏本人名牌 | 勾选「隐藏本人头顶名牌」，本机角色头顶的姓名、称号及随名牌显示的图标会一起隐藏。拍摄中取消勾选即可恢复。 |
| 只录特效 | 进棚时沿用角色当前可见度。要淡出角色，在「拍摄设置」点「设为 0.01」，或输入 0.01–1.00 后点「应用透明度」。 |
| 调整拍摄站位 | 在「拍摄设置」输入 X、Y、Z 并点「调整站位」。点「记住当前站位」，下次进棚会回到这里。也可以提前在「进棚设置」指定坐标。 |
| 返回旅馆 | 点 **退棚** 或输入 **/rtstudio 退棚**。录制棚先恢复本次接管的设置，再请求 Hyperborea 返回。面板确认回到原旅馆后撤销本次棚包设置。 |

「还原视距」「还原透明度」可在拍摄中单独使用。若已用其他工具改变透明度或手动滚动镜头，插件会保留新值。恢复原视距上限时，超出上限的镜头距离会收回到原范围。

本地加载适配当前测试机安装的 Hyperborea 构建。若换了不兼容的版本，面板会显示原因并提供原插件入口，可手动 **Load Zone / Revert**。通过原插件手动载入时，仍可切色、调整视距和透明度，棚内坐标可用原指南针调整。

## 录蓝扇 AE 序列

当前识别的是 `vfx/monster/gimmick3/eff/n4gb_b_g02c0a1.avfx`。可在普通场地打开绿幕面板录制。建议找有纹理、光照稳定的地面，便于整理器估算底色。

1. 完整解压程序包，保留 DLL 旁的 `FanExport` 目录。为 DX11 客户端安装可加载完整扩展的 ReShade 6.8.0。关闭客户端，将 `Native/FFxivGreenScreenDrawProbe.addon64` 放入 ReShade 的扩展搜索目录。在扩展旁新建 UTF-8 文件 `GreenScreenDrawProbe.lab.ini`，按配置示例填写已创建的本机固定磁盘记录目录。重启客户端，在 ReShade 中确认扩展已加载。[配置示例](../tools/graphics/draw_probe/README.md#设置采集器)
2. 取景时让蓝扇完整落在画面中央 **512 × 512 像素**内，扇尖和外缘都留空地。打开 `/rtstudio`，点 **录蓝扇 AE 序列**。等到「现在施放蓝扇」提示，先留一小段空场，再施放一次，特效消失后继续保持镜头和站位不动。插件请求连续 240 个游戏显示帧，整理器从中选出前后均有空场的一轮。
3. 面板提示就绪后点 **打开蓝扇 AE 目录**。在 After Effects 空工程中选择「文件 → 脚本 → 运行脚本文件」，打开该目录的 **导入蓝扇序列.jsx**。导入脚本使用 32 bpc、线性化 sRGB，建立「01 实速预览」和「02 逐帧核对与换底」。在第二个合成里更换最底层底图，查看暗底、相乘和相加三层，开关最上方的游戏原画即可对照。
4. 若提示采集扩展不可用，先检查扩展是否在当前游戏进程中加载，再核对设置文件和记录目录。若原始录制已保存、整理失败，读面板的具体原因。文件齐全时可点 **重试整理蓝扇 AE 序列**；若是特效触边、前后没有空场或地面不足以校色，请重新取景录制。[离线整理说明](../tools/graphics/draw_probe/README.md#录制与换底)

实速预览按记录中的显示时间在 60 fps 合成里播放。游戏录制中的帧间隔会变化，同一画面可跨越多个时间线采样点。已用一份游戏实录验证离线整理，选出 140 个连续显示帧，时长 2.161 秒；特效区域平均颜色误差约 5.25/255。其他光照、地面和施放需要各自对照。游戏中点击预览版按钮后手动施放、直至 AE 导入的完整流程仍待实机复核。

## 实机复核

1. 在旅馆确认 Hyperborea 已由卫月加载，先让其 **Enable Hyperborea** 保持未勾选。点击一次「进入摄影棚」，看到纯色布景后点另一种颜色，确认选中标记和布景随之改变。
2. 将镜头转向脚下，拉远拍一个熟悉的贴地技能，再换一次底色。切换本人名牌显示，确认姓名和称号一起隐藏、恢复。装有 Cammy 时，在棚里开一次自由镜头并移动机位。
3. 点击「退棚」，确认回到原旅馆，本人名牌、镜头范围、这次开启的自由镜头及 Hyperborea 开关均已恢复。再以 Hyperborea 开关原本已勾选的状态进退棚一次，确认退棚后它仍然开启。
4. v0.8.1 已实现换模、换选目标后还原和退棚自动请求还原。还需要在实机核对不同体型的骨架、动作、模型显示与退棚后的原外观。两种单帧输出的使用方法见[单帧取样说明](alpha-export.md)。

此前白棚停稳后的闪烁已通过实机验收。最新实拍里，天空和地面的切换色差有所减轻，蓝棚偶尔瞬切，切白棚时会短暂出现整块白墙、另一侧残留绿或蓝色的画面。过渡结束后白棚恢复正常。本版在拍摄前检测这些分块。转场外观和普通视角的人物补光继续列在待办中。

如需比较切色过渡，在旅馆展开「进棚设置」，勾选「试用天幕渐变修正」，再进棚。先将本机生成的试验棚包放到 DLL 旁，六色模式首次会自动导入 **RoundTable_CaptureStage_v0.19.pmp**。这份试验布景调整了黑、红、绿、蓝棚的天幕混合方式，天空和地面能否同步还需游戏内对照。新版默认选择 v0.18 六色稳定棚。已有旧五色布景也可以继续使用。
